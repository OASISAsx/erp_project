# ERP Platform

Monorepo สำหรับโปรเจ็ค ERP

- Frontend: Next 16, React, Ant Design, SCSS
- Backend: NestJS
- Database: PostgreSQL

## Run

```bash
npm install
npm run dev
```

Frontend: http://localhost:3000  
Backend: http://localhost:4000
